# Software Requirements untuk Jembatan Timbangan Sawit

## Web Server Requirements
- XAMPP 7.4+ atau LAMP Stack
- Apache HTTP Server 2.4+
- MySQL 5.7+ atau MariaDB 10.3+
- PHP 7.4+ atau 8.x

## PHP Extensions yang Dibutuhkan
- php_mysql (MySQL/MariaDB connection)
- php_mysqli (MySQL Improved Extension)
- php_mbstring (Multibyte string handling)
- php_json (JSON support)
- php_curl (HTTP requests)
- php_gd (Image processing)
- php_zip (Zip archive)
- php_xml (XML parsing)

## Python Requirements
- Python 3.7+
- pip (Python package manager)

## Python Packages (install via pip)
```
pyserial>=3.5
flask>=2.0.0
requests>=2.25.0
pyserial-asyncio>=0.6
```

## Hardware Requirements
- OS: Windows 7/10/11 atau Linux
- RAM: 4GB minimum, 8GB recommended
- Storage: 500MB available space
- Serial Port: COM port atau USB-to-Serial adapter
- Printer: Thermal printer ESC/POS compatible (optional)

## Network Requirements (untuk akses LAN/Internet)
- TCP/IP network
- Port 80 open (Apache)
- Port 3306 open (MySQL)
- Port 5001 open (Bridge service)

## Browser Requirements
- Chrome 90+
- Firefox 88+
- Edge 90+
- Safari 14+ (Mac)

## Optional Hardware
- RFID Reader (125kHz atau 13.56MHz)
- LED Display (untuk showing weight)
- Traffic Light system
- Webcam (untuk photo capture)
- Barcode scanner

## Notes:
- Untuk production use, disarankan menggunakan dedicated server
- Backup rutin database dan files
- Monitor system resource usage
- Update software regularly
